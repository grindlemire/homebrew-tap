# homebrew-tap

Homebrew formulae for my tools.

```
brew install grindlemire/tap/tabstack
```

| Formula | What it is |
| --- | --- |
| [tabstack](Formula/tabstack.rb) | The command line and cross-profile helper for the [tabstack](https://tabstack.alethi.dev) browser extension. Source: [grindlemire/tabstack](https://github.com/grindlemire/tabstack/tree/main/cmd/tabstack). |

Each formula installs a prebuilt binary from this repo's releases, made by the
tool's own release script.
